Getting started

1. Create an account

Enter an email and a password, then press Create account. We email you a confirmation link — open it, then come back and sign in. Until you confirm, the account does not exist yet, so signing in first will fail. Check your spam folder if the mail does not arrive in a minute.

2. Sign in

Use the same email and password. Tick Remember my email and the app will fill it in next time. Anyone in your household can add a task to your shared lists once they have joined with your invite code (Settings → Household).

3. Forgot password

Press Forgot password?, enter your email, and we send a reset link. Open it and choose a new one. The reset link works only once.

No signal? Everything keeps working offline and syncs when you are back online. Signing out clears this device's copy, so anything that never synced would be lost — wait for a connection first.

Local model (Ollama)

Answers questions and reads captured sentences using a model running on this computer. Nothing is sent anywhere, and it costs nothing. When it is off or unreachable, the app falls back to the cloud provider.

Must be reachable from this browser. On this computer, http://localhost:11434 works. To use it from your phone, put a free Cloudflare tunnel in front of Ollama and paste that address here instead.

Use this from a phone (free)

In a terminal on the computer running Ollama:

cloudflared tunnel --url http://localhost:11434

It prints an address like https://something.trycloudflare.com. Paste that above and save. A quick tunnel gives a new address every time it restarts, so paste the new one after each restart — the app tells you when the address it has has gone stale.

Install one with ollama pull llama3.2.
